MathKeyboard - examples

Each example is a small exercise: a question, a keyboard configured for its kind of answer, and a Submit button that checks the answer with mathCheck and shows the grade and the feedback - change the answer and submit again as often as you like. Click a keyboard to type into it with the computer keyboard too. Next to each one: the code.

1. Numbers only

A numeric answer: digits, operations, fractions, powers, roots and π - no variables, no "=", no functions or structures. The check notes a root left in the denominator.

Write the square root of one half.

5. An exercise with units (Hebrew)

    
A numeric answer with its unit. The student types the number and chooses the unit with the units
       key [u]. The unit is not part of getLatex() / getAST(): the page reads it with
       getUnit() and getUnitScale() (the factor to the base unit: km → 1000 m).

    

      רוכב אופניים נוסע במהירות 12 קמ"ש במשך 10 דקות. מהו המרחק שעבר? ציינו גם יחידות.

6. Complex numbers (Hebrew)

    
The keyboard with i (complexNumbers: true; in the x… panel, or the
       letter i on the computer keyboard). Answers with i are computed as complex numbers, so (3+4i)⁻¹ and
       0.12 − 0.16i have the same value; the rules require the form a + bi and the rubric takes 20% for i left in
       the denominator.

    

      כתבו את המספר \((3+4i)^{-1}\) בצורה \(a+bi\).
